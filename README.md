# Jammo Kick

A small Unity gameplay test featuring character movement, ball-kicking mechanics, cinematic camera transitions, and goal celebration effects.

## Unity Version

Unity 2022.3.10f1 LTS

## Controls

- `WASD`: Move the character
- `Kick`: Kick the nearest ball when in range
- `Auto Kick`: Kick the farthest available ball toward its nearest goal
- `Reset`: Reload the gameplay scene

## Features

- Free character movement with field boundaries
- Character rotation based on movement direction
- Idle and Run animations
- Top-down player-follow camera
- Context-sensitive Kick button
- Automatic ball selection and nearest-goal targeting
- Cinematic ball-follow camera with custom transitions
- Goal confetti effects
- Scene reset functionality
- Responsive mobile-style UI

## Project Structure

- `Assets/_Project/Scenes`: Main gameplay scene
- `Assets/_Project/Scripts`: Gameplay scripts
- `Assets/_Project/Prefabs`: Project prefabs

## How to Run

1. Open the project using Unity 2022.3.10f1.
2. Open `Assets/_Project/Scenes/Main.unity`.
3. Enter Play Mode.
